# Objective of this Project
The goal of this project was to transform hospital data into meaningful insights that can support better decision-making, improve operational efficiency, and enhance healthcare service planning.

# Overview
The overview dashboard presents key hospital indicators through interactive visualizations.

Key components:

Total bill amount.

Admission, discharge, and follow-up dates.

Health insurance amount versus billing amount by medical test.

Patient diagnosis distribution.

Bed occupancy comparison.

Interactive filters for Doctor, Month, Diagnosis, and Patient ID.

# Decomposition Tree Analysis

The Decomposition Tree enables users to drill down into diagnosis records by medical test, bed occupancy category, and year.

An example analysis path is:

Total diagnosis records → Viral Infection → Blood Test → Private → Year

This feature helps users investigate subsets of hospital data and explore relationships between different categories.
